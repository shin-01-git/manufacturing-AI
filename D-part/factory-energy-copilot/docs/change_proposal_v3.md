# 변경 제안 v3 (멘토링 반영) — requirements/design 수정 제안 메모

requirements.md / design.md는 수정하지 않았다. 아래는 팀 승인 후 반영할 제안이다.

## 1. IA·화면 구조 (REQ-UI 계열)
- 페이지: 홈 / 설비별 분석 / 이상치 모니터링 / AI Copilot / 설정 (기존 개요·예측·이상 탐지·AI 중 개요·예측은 홈으로 통합).
- 내비게이션은 왼쪽 사이드바 세로 메뉴. 필터는 페이지 헤더 필터 바(기간 단위 시간/일/주, 날짜, 알림 벨).
- 신규 기능: 알림 벨 팝오버, 설정 페이지(단가·탄소계수·탄소 가격·알림 임계값), 이상 유형 칩 필터, 탐지 타임라인, 설비별 분석(추이·비교·요일×시간 부하 패턴).

## 2. 데이터 / 아티팩트 (design 데이터 계약)
| 항목 | 상태 | 비고 |
|---|---|---|
| `actual_vs_pred.csv` | **추가됨** (evaluate 단계 산출) | 실제 vs 예측 선과 예측구간 이탈 경고에 필요. 학습·예측에는 사용하지 않음 |

## 3. 용어
- "탄소세" 대신 **"예상 탄소비용 (가정 단가 기준)"**. 한국은 탄소세가 아닌 배출권거래제(K-ETS)라 발표 질문 방지. 단가는 설정에서 사용자가 입력(기본 빈칸, 임의 시장가 하드코딩 금지).
- 탄소 단위는 정답 척도(pow × 0.424)이며 단위 미확인. 비용 계산은 ÷1000(kg→t) 후 단가를 곱한다.

## 4. 열린 항목
- O-1/O-8 기존 열린 항목 유지.
- OPENAI_MODEL 기본값은 이미 소형 모델(`gpt-4o-mini`). 팀이 정한 모델명을 환경변수로 넣는다.
- 홈 "예측 근거"(분석 플로우)는 발표용 선택 기능으로 구현했으나 필수는 아님.

## 5. 역할 (REQ-USER 변경 제안)
- 역할을 2개(설비 관리/에너지 관리)에서 **3개(+ 경영진, role key: executive)** 로 확장하는 안. 개인 이름 없이 역할명만 사용하는 원칙은 유지.
- 역할이 바꾸는 것: 사이드바 메뉴 구성, 홈 KPI 5종과 하단 패널 순서, 홈 예측 근거 섹션 노출(에너지만), 이상치 페이지 상세도(경영진은 요약만), AI Copilot 기본 브리핑 대상과 추천 질문. 데이터 값은 역할과 무관.
- 경영진은 설정/설비별 분석 메뉴가 숨겨진다(읽기 중심). 이 구성은 팀 승인 후 확정.
